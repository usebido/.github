# Bido

Bido is the universal checkout layer for agentic commerce.

We enable AI agents to discover products, select the best option, and complete purchases across online stores without forcing users to leave the conversation.

Instead of integrating every merchant individually, Bido combines product discovery, intent matching, payment authorization, and browser-based checkout execution into a single infrastructure layer.

## What Bido does

- Searches products across ecommerce stores
- Understands user purchase intent
- Returns structured product recommendations
- Collects shipping and payment authorization securely
- Executes checkout on the merchant website
- Tracks the purchase until completion

## Interfaces

Bido can power commerce inside:

- ChatGPT and MCP clients
- WhatsApp
- Instagram
- SMS and messaging agents
- AI assistants and agent applications
